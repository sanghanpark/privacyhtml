# 배포 방법

가장 쉬운 방법: GitHub Pages

## 1) GitHub 새 저장소 만들기
- 예: `my-app-support-site`

## 2) 이 폴더의 파일 업로드
- `index.html`
- `privacy.html`

## 3) GitHub Pages 켜기
- 저장소 `Settings` → `Pages`
- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

## 4) 공개 URL 확인
- 예: `https://사용자이름.github.io/my-app-support-site/`
- 개인정보처리방침 URL:
  `https://사용자이름.github.io/my-app-support-site/privacy.html`

## 5) Play Console에 넣기
- 지원 이메일: 실제 운영 이메일
- 개인정보처리방침 URL: 위 `privacy.html` 공개 주소

## 꼭 수정할 것
- `your-support-email@example.com`
- `홍길동 / YOUR COMPANY NAME`
- `YOUR EMAIL SERVICE NAME`
- `YOUR SERVER OR HOSTING NAME`
- `YOUR ANALYTICS OR CRASH SERVICE NAME`
- 앱 이름, 시행일, 실제 데이터 처리 방식
